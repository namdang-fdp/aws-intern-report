### Internship Overview

During my internship at **Amazon Web Services (AWS)**, I had the invaluable opportunity to learn, practice, and apply my academic knowledge to a real-world cloud computing environment.

I participated in building the **BandUp IELTS Learning Platform** - a comprehensive AI-powered application that helps students prepare for IELTS exams through automated Writing and Speaking evaluations, utilizing a modern full-stack architecture on AWS.

---

### Key Achievements

Through this project, I developed and improved skills in:

**Cloud Architecture & AWS Services:**

-   Designed and deployed a containerized architecture using **Amazon ECS (Fargate)** for both Frontend and Backend services.
-   Configured secure VPC networking with Public/Private subnets, NAT Gateways, and Application Load Balancers.
-   Managed high-availability data storage with **Amazon RDS (PostgreSQL)** and **Amazon ElastiCache (Redis)** for session management.
-   Implemented secure content delivery using **Amazon CloudFront** and **S3**.

**Development & DevOps:**

-   Developed robust RESTful APIs using **Java Spring Boot** and implemented Spring Security for authentication (OAuth2/JWT).
-   Built a responsive and interactive Frontend using **Next.js (React)** and **Bun**.
-   Set up CI/CD pipelines to automate build and deployment processes to AWS.
-   Practiced Infrastructure as Code principles (if applicable) and containerization with Docker.

**AI/ML Integration:**

-   Integrated **Google Gemini API** for generative AI feedback in Writing and Speaking modules.
-   Implemented **Amazon Bedrock** for advanced AI tasks and evaluations.
-   Optimized API calls and prompt engineering to ensure accurate IELTS band scoring.
