### Week 2 Outcomes

**Technical Proficiency Gained:**

_IaaS & Network Engineering:_

-   **VPC Mastery:** Attained comprehensive command over Virtual Private Cloud architecture.
-   **Resource Orchestration:** Successfully provisioned the complete network stack for EC2:
    -   **Network Segmentation:** Configured Granular **Subnets** for logical isolation.
    -   **Edge Connectivity:** Established **Internet Gateway** for external access.
    -   **Traffic Governance:** Defined **Route Tables** to strictly control packet flow.
    -   **Instance Firewall:** Implemented **Security Groups** for stateful traffic filtering.
-   **Identity Integration:** Leveraged **IAM Roles** and instance profiles to secure EC2 credentials.
-   **Financial Guardrails:** Deployed cost management strategies using AWS Budgets.

**Strategic Insights (Cloud Day):**

-   **Community Integration:** Successfully networked with AWS mentors and industry veterans.
-   **Market Intelligence:** Gained critical visibility into the trajectory of AI and Data technologies.
-   **Future Readiness:** Validated the exponential market demand for AI-driven cloud solutions.

**Core Insights:**

-   **VPC** is the non-negotiable bedrock of AWS networking; its design dictates security and connectivity.
-   **Security Groups** function as the primary line of defense (virtual firewall) at the compute level.
-   **IAM Roles** are essential for "Credential-less" architecture, removing hardcoded secrets from code.
-   **Proactive Monitoring** via AWS Budgets is the first step in Cloud Financial Management (FinOps).
